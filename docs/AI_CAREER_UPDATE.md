# AI 与求职模块实现说明

2026-11-05，本地分支 work/prep-career-ai。本轮不上传。

后端 assistant.mjs 提供4个只读上下文工具：get_profile/get_learning_tasks/find_catalog_jobs/get_interview_history。工具在服务端确定性调用、收集后一次性提交给模型，不启用任意抓取或多轮Agent循环；不同模式有独立prompt和输出结构。候选岗位来自项目目录，保留官网、核验时间、资格与状态，AI返回ID必须在候选集合中。当前不承诺全网实时在招搜索。

模式：personal_plan、career_chat、application_plan、interview_plan；旧answer_feedback保持API兼容，前端五题模块移除。公共输出校验、邀请原子配额及幂等复用。

学习建议、采用任务、面试建议和真实轮次分开保存。AI日期任务采用前检查日期、容量及已有任务；不得静默改变真实投递状态。职业建议保存在careerAI，按备份校验往返。简单直接发送取代强制预览弹窗，原有输出纯文本、限长和费用控制保留。

Offer按本人录入的条件即时更新对照表，不接企业消息。新增直接Offer录入入口，台账和Offer卡片沿用同一数据。UI统一系统中文字体、正文15px、标题21px，AI双列等高，手机单列。

验证记录：101项单元与HTTP契约测试通过，构建通过。Edge合成响应端到端通过：AI生成→采用任务→完成记录→进度更新、对话刷新、直接录入Offer→对比表、AI面试建议→采用轮次→完成与经验、投递建议展示、390px无溢出。两个AI面板实测均590px高，已核对桌面截图。本轮未测试真实模型与计费，未推送远端。用户历史自测答案在数据中保留，界面移除。
