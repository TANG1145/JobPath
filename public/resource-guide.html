项目修复与运行

以下是 JobPath 对上游固定版本的本地修复，不代表上游仓库已经修复。先应用补丁，再安装依赖。需要 Git、Node.js 24 和 Python 3（静态服务）。补丁仅更改依赖、开发命令和测试范围，保留原仓库 LICENSE。

TodoMVC / JavaScript ES6

升级构建依赖，移除旧开发服务器；用 Python 提供本机静态页面。新增、编辑、完成、过滤均应验证。此示例使用内存存储，刷新清空，不是持久化模板。

官方项目 · 下载依赖修复补丁

git clone https://github.com/tastejs/todomvc.git
cd todomvc
git checkout ff43b02e59dfa604386bb382034b2cd07c2bcd8a
git apply /补丁保存位置/todomvc.patch
cd examples/javascript-es6
npm ci --ignore-scripts
npm audit
npm run build
npm run serve

打开 http://127.0.0.1:7002 。请独立添加筛选条件并记录个人贡献，不将克隆代码作为原创。

Playwright / API Mocking 与 Clock

锁定 Playwright 1.64.1；包许可字段与上游 MIT LICENSE 对齐。学习范围为 API mock、响应修改、HAR录制/回放和时钟控制，共7个用例。上游商店演示域名连接失败，8个商店用例不再作为本资源；没有把它们标为通过。

官方项目 · 下载依赖与配置补丁

git clone https://github.com/microsoft/playwright-examples.git
cd playwright-examples
git checkout 4eb82aedf58321da90332e5f7316b64d5914a6b1
git apply /补丁保存位置/playwright.patch
npm ci --ignore-scripts
npm audit
npx playwright install chromium firefox webkit
npx playwright test --config jobpath.config.ts

示例需访问 demo.playwright.dev；必要时通过 AUDIT_PROXY 指定你已有的代理。串行运行以防多个浏览器同时改写同一HAR文件。独立新增错误路径测试，保留原项目版权。
