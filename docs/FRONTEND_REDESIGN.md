# 前端重塑说明 · tb-dev

日期：2026-10-30　分支：`tb-dev`　状态：第一轮可运行原型（不是最终视觉稿）

## 1. 为什么改

仓库主人对 v0.7 的反馈：

> 正在加 AI 功能。我目前看下来还是太乱了，主线不突出，UI 设计也不行。

这不是配色问题，而是三个问题叠在一起：

1. **信息架构没有主线**：机会、备战、求职各自堆功能，用户不知道"现在该做什么"。
2. **视觉层级失效**：卡带装饰、英文眉标、编号、等宽正文、低对比小字占据主视觉；8 个 panel 等权。
3. **动作层级反了**：最大按钮是"录入私人 JD"，而真正的下一步"设为目标 / 开始任务 / 记录进展"埋在列表里。

这一轮先解决"用户从进入到完成第一件事"的路径，不改领域模型、不改后端、不重写技术栈。

## 2. 主线

> **选一个目标岗位 → 看清差距 → 今天做一件事 → 留下证据 → 投递/复盘。**

规则：

- 没有目标岗位时，默认进入"机会"；有目标时，默认进入"备战"。
- 目标岗位常驻顶栏；所有备战内容围绕它。
- 每屏只保留一个主 CTA：
  - 机会：**设为目标**（次要：粘贴 JD、收藏、原文）
  - 备战：**打开任务 / 生成计划**
  - 求职：**添加记录 / 记录复盘**
  - 设置：**编辑画像 / 导出备份**
- 没有目标时不允许生成计划（`previewPlan` 会拦截）。
- AI 不是一级入口，关闭时不显示任何 AI 按钮。

## 3. 路由与页面

使用 hash 路由，刷新、后退、直达都可用：

| 路由 | 页面 | 只回答 |
| --- | --- | --- |
| `#/opportunities` | 机会 | 我要投什么？ |
| `#/prepare` | 备战 | 今天做什么？ |
| `#/career` | 求职 | 下一步是什么？ |
| `#/settings` | 设置 | 数据与 AI 状态 |

### 机会

- 顶部一句主线说明 + 两个动作：粘贴 JD、调整时间。
- 首次访问显示"两步开始"卡：设定时间 → 选目标。
- 先列"我的岗位"（私人 JD + 当前目标快照），再列官方目录。
- 官方岗位卡：公司/职位/城市/类型/状态 + 设为目标 + 收藏 + 原文；要求与核验说明折叠。
- 历史/已关闭岗位单独折叠，不混入当前机会。
- 侧栏：方向建议（无画像时显示"先完成画像"）、每周节奏、核验声明。

### 备战

- 顶部：目标岗位标题、公司/城市；主动作只有"生成计划/重排"。
- 主卡"今天"：最多 3 项任务；没有任务时说明下一步，不堆空面板。
- 差距卡：只展示未达标的前 3 项；无结构化要求时给"整理岗位要求"主按钮。
- "本周路线""学习资料"折叠，不抢主卡注意力。
- 侧栏：目标岗位、本周进度、最近证据、练习入口。

### 求职

- 阶段统计条 + 投递记录列表；记录卡可直接改阶段、编辑、加轮次、填 Offer。
- 轮次与阶段历史折叠在记录卡内。
- Offer 对比、五题练习、简历核查、复盘记录全部折叠为次级区域。
- 侧栏只保留最近 7 天回顾和一条下一步建议。

### 设置

- 画像摘要 + 编辑。
- 备份/恢复/清空。
- AI 状态：关闭时只显示"AI 未开启"，不显示邀请输入或按钮；开启时才出现邀请与额度。
- 关于：版本、数据位置、服务端、AI 状态。

## 4. 视觉系统

保留"卡带未来主义"作为外壳，不再让它盖过内容：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#12140f` | 页面底色 |
| `--surface` | `#1b1e17` | 卡片 |
| `--text` | `#f1ede0` | 正文 |
| `--muted` | `#a8ad9b` | 次要信息 |
| `--accent` | `#f2a33c` | 主按钮/关键数字 |
| `--cream` | `#ece5d2` | 顶栏 |
| `--ok / --warn / --danger` | `#8ed6a5 / #f2b45c / #e28b76` | 状态 |

- 正文：系统 sans（PingFang / 微软雅黑 / system-ui），15px / 1.65；等宽只用于眉标、数字、状态。
- 桌面：内容最大宽 1180，主列 + 330 侧栏；移动：单列 + 固定底部四导航。
- 卡片只有一层边框和一层圆角；去掉装饰性编号、`SYS /`、`V.0.x`、条纹、LED、散热孔。
- 视觉语言：**信号带 / 方向雷达 / 本周容量刻度盘 / 飞行路径 / 登机牌式岗位卡（左侧序号 + 虚线） / 鼠标聚光 / 滚动进度 / 细颗粒与扫描线**。全部是原生 CSS/JS，不引入 React Bits、Uiverse 或外部 CDN，避免"组件库拼贴感"。
- 动画只做三件事：雷达扫描、信号带滚动、主按钮高光；`prefers-reduced-motion` 下全部关闭。
- 顶栏 64px（移动 56px），只保留品牌、当前目标、四个导航、保存状态。
- 所有可交互元素有 `:focus-visible` 描边；`prefers-reduced-motion` 下关闭过渡。
- 320 / 390 / 768px 实测无横向溢出。

## 5. AI 的可见性

当前 AI 默认关闭，因此：

- `extraFeatures` 时代散落的 AI 按钮全部移除。
- AI 关闭时，机会/备战/求职不出现 AI 按钮；设置页只显示"AI 未开启"。
- AI 开启时，设置页出现邀请与额度；练习区出现"AI 反馈"，反馈保存为草稿并标注"需核实"。
- 下一轮再补：JD 整理、任务证据反馈、面试追问三个上下文入口；不做 AI 首页、不做聊天、不做 AI 导航。

## 6. 代码结构

```
index.html                  app 外壳 + dialog + toast
style.css                   设计系统与响应式
src/app.js                  状态、保存、路由、弹窗、动作绑定
src/ui/components.js        esc / badge / card / empty / meter
src/ui/views.js             四个页面的纯渲染函数
```

保持不变：

- `src/domain.js`、`workflow.js`、`planning.js`、`applications.js`、`drafts.js`、`storage.js`：领域与存储逻辑未改。
- `backend/*`、`server.mjs`、配额与 AI 网关未改。
- 备份 schema、IndexedDB 版本、`state` 字段未改；旧备份仍可导入。

数据属性约定：

- `data-target-job` / `data-target-public`：设为目标
- `data-save-public`：收藏官方快照
- `data-edit-job` / `data-apply-job` / `data-task`
- `data-stage` / `data-editapp` / `data-round` / `data-offer`
- `data-action`：profile / jd / plan / review / export / import / clear / application

## 8. 已知限制

1. **岗位时间依赖未修**：`src/jobs.js` 的 `checkedAt = 2026-10-30T05:00Z`，30 天后会全部转历史；应用本身会按产品规则降级，但演示和 E2E 需要固定时钟或更新快照数据（已给 E2E 加 `page.clock`，应用侧待修）。
2. **`app.js` 仍是单文件**：已从"压缩长行"改成可读格式，但仍约千行；下一轮按 `actions/`、`modals/` 拆。
3. **AI JD 整理未恢复到新 UI**：网关与测试仍在，UI 入口留到下一轮。
4. **IndexedDB 仍是单 `state` 记录**：备份兼容，但全量写和跨标签冲突的根因未变。
5. **未部署**：仍是本地证据版，没有公网 URL。
6. **`app.js` 的 `beforeunload` / 草稿提示依赖浏览器原生 confirm**：Safari/Firefox 行为可能不同，需在真机复核。
