# 四模块调整验收

日期：2026-11-06。分支：work/prep-career-ai。仅本地交付，未推送GitHub，未读取个人API配置；docs/original原始课程文档保持不变。

## 已完成

1. **备战 / 备选岗位**：AI投递参考顺序移出求职记录，结合主要目标类型、画像、现有任务生成同期备选岗位与行动日期；提示词要求说明复用技能及额外投入。主要目标不会因生成或采用建议被替换。结果关联目标，异步返回不会混入新目标；支持加入投递记录，偏好输入在切换页面时保留。
2. **求职 / 投递记录**：序号、白紫交替底色、增加段落留白；阶段支持预设和自定义，保留阶段历史、刷新与备份。自定义阶段在站内表单填写，显示时作为纯文本。
3. **求职 / 面试日历**：替代原AI面试规划区域；直接读取求职记录中的轮次。全天时间轴、周/日视图、日期导航、今天定位、起止时间、重叠并排、短时段防遮挡、已完成状态、日期/时间待定区域。点击日程编辑同一条原始记录，选择关联公司后可创建面试。
4. **求职 / 每日回顾**：左侧月份文件夹、右侧Markdown编辑或阅读；支持任意日期、工具栏、草稿刷新恢复、保存、删除、旧记录查看和备份。使用marked与DOMPurify渲染标题、列表、链接、表格、引用、代码块，过滤可执行HTML。外部链接在新标签打开。

## 视觉验收

统一浅色紫系、圆角、按钮层级、字号和留白。桌面日历展示整周，手机默认日视图；宽日历在组件内滚动，不撑开页面。日志编辑器占据主要内容区域，手机导航折到上方。实际查看了桌面日历、桌面日志及手机日历截图，修正事件标题换行造成的截断。

没有新增动效演示按钮、配额或反复确认提示。真实保存失败仍在原位置显示错误并保留输入；删除日志保留一次确认。

## 验收路线

1. 在备战设定主要目标，进入备选岗位生成建议，加入一条投递记录，核对主要目标不变。
2. 求职记录选择自定义阶段；新增两场重叠面试，填写日期及起止时间。
3. 面试日历切换周/日，点击事件编辑；返回记录核对一致。
4. 每日回顾输入标题、列表、表格与代码块，切换阅读模式、保存，并通过月份导航打开历史。
5. 设置导出备份，恢复后核对自定义阶段、面试时间、日志和原学习计划。
