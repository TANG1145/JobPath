# 招聘列表与独立详情

2026-10-31，tjj 分支。仅修改机会模块的招聘展示，不改招聘源数据、收藏结构或备战模块。

- 列表改为职位、公司、可展开城市、招聘类型、核心条件和简短简介，操作为收藏与查看详情。
- 独立详情保留原列表 DOM，返回时恢复筛选值、滚动位置与触发按钮焦点。
- 桌面为左侧岗位内容与技能、右侧申请条件；手机优先展示申请条件，底部固定收藏与官网入口。
- 统一使用“前往官网 ↗”，打开官网不等于提交申请；收藏沿用原地持久保存、撤销和取消收藏。
- 工作对象不再单列，与职责合并为岗位内容；“先选择岗位意向”归入申请步骤。申请对象与毕业届别在原文含义完整的前提下分组，混合句保留为“毕业届别与申请对象”，不拆散“或、优先”等关系。
- 不展示与招聘类型无关的空时长字段；没有来源的要求仍为未披露，不写成不限。
- 摘要解释收进“招聘官网摘要 ⓘ”；底部“来源与核验”合并核验状态、北京时间、来源与原始摘录。
- 保留深绿、米白、琥珀风格，标题 24–28px，正文 15–16px。无横向溢出，折叠及操作支持键盘。
