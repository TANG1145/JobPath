# v0.8 AI 增强阶段：模拟联调交付

2026-10-30。三个场景已接入 React 界面及本机模拟后端。真实 AI 仍关闭，不部署。此交付不等于真实模型质量、价格或公网验收完成。

## 可用流程

- JD 整理：岗位整理页 → 预览已保存原文/版本 → 明确确认本机发送 → 查看模拟要求及未知项 → 审阅后保存未确认草稿 → 恢复草稿，逐项编辑确认。已有手动草稿会阻止接收，不静默覆盖。
- 项目表达：岗位材料页 → 明确勾选成果与用途 → 预览成果事实、岗位要求及版本 → 模拟结果附事实引用 → 审阅后生成未确认材料版本。需本人编辑并确认后才能用于投递。
- 回答反馈：保存回答后 → 预览真实题目、答案版本、评价维度 → 引用式模拟反馈 → 审阅保存。绑定原答案；修改回答后仍可回看旧结果，不把旧反馈当作新反馈。建议转任务继续要求本人确认，不改技能等级。

模拟器只引用或复述已提供内容，JD 技能标“待核实技能”，不会伪装真实智能提取。反馈同样不评判能力；所有页面标明 deterministic-fixture-v1。

每次发送前显示完整输入和版本、模式、日额/会话额度。取消预览不发送。请求先存本机历史，再发送；切页、刷新、网络丢响应后可用同一标识找回。成功/失败结果可回看。再次请求须重新预览确认，没有自动重试。

## 接口与数据

- `GET /api/scenes/quota`：本机模拟额度；答案场景可传 session 参数。
- `POST /api/scenes`：X-Client-Id、Idempotency-Key，严格的 scene/sceneVersion/consent/contextVersions/payload。
- 公共输入/输出契约：shared/ai-scenes.js。拒绝任意 system、上游地址和额外字段；检查引用来自原文/选中成果/原答案。HTTP 最大 48 KB，各文本至多 6000 字符，成果最多 5 项。
- `/api/health` 明确区分 aiEnabled=false 与 sceneMode=mock。模拟端点不调用 DeepSeek，不因传入字段切换成真实模型。
- 浏览器正式写入仍经过唯一仓储；历史表保存请求/结果，备份自动包含这些记录。应用结果前检查上下文 revision，原子写入结果与“已采纳”标记，双击/并发不会重复创建材料或反馈。
- SQLite 本机模拟缓存 `.local/scenes-mock.sqlite` 保存客户端标识、请求哈希、额度及响应结果（可能含私人引用），不保存输入全文。浏览器保留完整已同意发送内容。缓存和数据库均被 Git 忽略。清空浏览器不清空服务缓存；这是本地联调数据，不是云同步。

## 模拟限额（暂定，不是正式价格方案）

| 项目 | 当前限制 |
|---|---|
| 单浏览器身份 | UTC 每日 12 次 |
| 回答会话 | 累计 3 次；预览显示剩余次数 |
| 并发 | 每身份 1 个，全局 3 个 |
| 本机模拟窗口 | 累计 200 个请求 |
| 模拟预算 | 每次预占 60000 单位，总额 12000000 单位，无货币含义 |

同键同内容返回缓存，不再次占额；同键不同内容拒绝；处理中同键返回 pending。失败/超时保留占额；服务重启时未完成请求记为结果未知，不偷偷重跑。超时后不采纳迟到结果。所有限额在服务端同一 SQLite 事务内检查和预留。

这是单进程本机模拟服务，身份是浏览器随机 ID，不具备真实账号防绕过能力；清除身份或创建新浏览器不是生产级防滥用方案。原邀请制真实网关额度独立保留，不挪用为新会话预算。真实接入前必须校准输入/输出/计费并统一可信身份、会话预算及结果生命周期。

## 验证与边界

- 21 组确定性契约样本 = 3 场景 × 7 类输入（普通、未知、诱导虚构、矛盾、无关、缺指标、HTML 字面文本），另测缺上下文、额外字段、未同意与伪造引用。只证明流程/格式与引用检查，不证明内容质量。
- 服务端测试：缓存幂等、换内容拒绝、同键/异键并发、日额、会话额、全局额、预算、超时、坏 JSON、错误引用、异常降级、重启恢复。
- 浏览器测试：三个入口、预览取消、人工审阅、未确认材料隔离、旧答案反馈、断网找回、真实模拟日额耗尽、上下文过期禁止应用、504/422 失败持久显示。
- 真实 AI 调用、供应商超时及账单、20 个以上真实输出人工质量评审、五位用户任务验证、公网验收与部署决策仍未完成。不得据本次模拟测试启用真实 AI 或发布。
