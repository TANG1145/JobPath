# 本机 AI 配置指南

更新：2026-11-05。推荐在网页配置，无需命令行邀请。

## 配置步骤

1. 在 [DeepSeek开发者平台](https://platform.deepseek.com/api_keys) 自行创建API Key。
2. 启动JobPath，固定打开 http://127.0.0.1:5175 。
3. 进入 **设置 → AI连接**，将Key填入密码输入框，勾选“启用AI服务”。
4. 点击“验证连接并保存”。应用验证官方/models接口，不生成答案。成功后立即生效，无需重启。
5. 在备战描述学习需求，点击“生成个性化计划”。

已有配置时Key可留空以保留原Key，仅更改启用状态。停用按钮即时生效，学习与求职记录保留。网页不能替供应商创建Key。

Key只由应用保存在本机服务端配置中，不回显、不进入浏览器备份，不提交Git。助手不会读取该配置文件。日常使用无需打开文件或把Key发到聊天。

## 本轮取消的门槛

网站不再使用个人/全站日次数、累计次数、估算费用预算、金额预留熔断或试用到期阻止调用；旧到期字段不影响有效本机连接。旧账本保留调用状态与重复提交标识，无需删库。AI_PRICING_REVIEWED、AI_WINDOW_END和AI_DAILY_LIMIT等旧变量不再控制启用或限额。

供应商实际账户权限、余额、限流和模型能力仍由供应商决定。网站会显示实际连接或模型错误，不伪造生成结果。

## 常见情况

| 页面情况 | 处理 |
|---|---|
| AI服务已停用 | 设置→AI连接，勾选启用并保存 |
| 本机连接尚未建立 | 刷新网页，或重新启动本地服务；不用复制邀请，不必重新输入已保存的Key |
| 密钥验证失败 | 在供应商后台核对Key与权限，再自行重新填写；错误验证不覆盖旧配置 |
| 模型供应商返回错误/限流 | 核对供应商账户与网络，稍后主动重试 |
| 生成超时 | 当前输入保留，检查网络后重试 |
| 计划无法采用 | 先选择目标岗位；任务须有有效日期、非空内容和正整数估时 |
| 网页打不开 | 双击启动网站.cmd，固定访问127.0.0.1:5175，不直接打开HTML文件 |

空或旧Bearer覆盖有效本机会话的问题已修复。生成前先等待连接检查；有效本机会话优先。没有每日额度或预算错误的应用代码路径。

## 实现与验证范围

当前固定连接DeepSeek服务端网关，模型名见AI连接状态，输出采用JSON非流式结构。当前请求输出能力设置为8192 tokens；实际模型与供应商上下文边界仍存在。

本轮用合成配置、模拟供应商和独立测试浏览器验证，不读取真实Key、不产生真实模型调用费用。真实回答质量需使用者在网页主动测试。
