# 理想 JD 工作流：第 7～10 项

2026-10-30，tjj 分支。保留 v0.7 的配色、导航和物理分类球；真实 AI 关闭，不部署、不合并 main。

## 本轮行为

- 招聘列表点“收藏岗位”原地持久保存，无确认弹窗、不离开列表；成功后按钮为“已收藏”，旁边有明确“取消收藏”。反馈提供“查看”和“撤销”，仅点查看才跳到收藏。连续收藏不修改备战方向、不提交申请。
- 所有收藏统一“查看与整理”入口，显示“招聘摘要 / 已补充原文 / 要求已整理”。摘要补充入口带入公司、职位、方向和来源；本人确认补充原文后，支持的方向可显式设为目标，保存本身不自动设目标。
- 当前备战目标独立置顶；其他收藏是紧凑列表，主操作只保留查看与整理，编辑、归档、取消收藏放在更多菜单。资格核对独立展示，并说明“符合”由本人确认。
- 支持最近收藏、最近更新、截止日期排序；正在考虑/已归档/全部收藏筛选；显示“找到 N 条 / 共 M 条”，并提供清空筛选。没有时间的旧记录不补造收藏日期，排序在后。置顶目标不受下方筛选影响，并明确提示。
- 录入覆盖全部 18 个职业方向，默认请选择；从招聘分类进入时带入当前方向。职位、方向、JD 内容必填，公司可后补；标题、公司、方向、来源可编辑。保存后可继续整理或返回收藏。
- 无模板的 15 个方向可收藏、编辑原文、手动整理要求、使用本机模拟整理和记录台账；暂不能设为备战目标或生成对应方向计划，界面说明原因。已有三方向模板保持原状。要求编辑支持补充自定义技能。
- 空收藏提供探索岗位与粘贴 JD 两个入口。

## 数据兼容与保护

继续使用现有本地数据库及备份格式。旧 recruitmentSaves 记录先在统一列表中展示；打开详情时转换为具备相同事实字段的 JD 记录，保留公开记录 ID、来源、摘要、资格信息等，避免重复收藏。不批量覆盖旧库。

取消收藏隐藏 JD 记录但保留已有任务和投递引用；取消当前目标会明确反馈解除绑定，撤销可恢复。归档当前目标同样解除绑定，但保留已有成果。存储失败回滚本次修改，不显示成功。新职业方向纳入备份校验，备战方向仍限定于已有三个模板。

官方岗位如已有原文与要求证据，收藏时优先保留原文，避免把摘要替换成证据无法匹配的内容；覆盖了全部种子招聘记录的收藏后备份校验。
