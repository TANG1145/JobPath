# 启职 JobPath v0.6

岗位要求驱动的本地求职备战工作台，卡带未来主义风格。私有仓库：https://github.com/TANG1145/JobPath 。不部署上线，真实 AI 默认关闭。

## 运行与测试

Node.js 24/25 推荐（最低22.13）。运行应用无需第三方生产依赖。

```sh
npm ci
npm run dev
npm test
npx playwright install chromium firefox webkit
npm run test:e2e
npm run build
```

本机访问 http://127.0.0.1:5173 。构建在dist/，仅包含客户端与资源目录，不包含服务端密钥、邀请、SQLite或后端实现。GitHub Actions只执行测试和构建，不部署。

## 功能

画像与可解释方向建议、私人JD、可视化要求分组和原文依据、技能差距、七天详细计划、4/8周逐周容量概览与先修图、任务证据、历史归档、12条官方岗位快照、历史状态隔离与版本化收藏，24条分方向资源及同技能文档替代、投递台账与二次确认、五题练习、简历核查、复盘补缺、结构化Offer对比与旧备注保留、本地JSON备份和版本冲突保护。

AI网关支持JD提取与回答反馈；发送预览、逐次同意、邀请与额度、幂等、原子费用预留、超时降级、模型输出校验。草稿经用户再次确认才保存。接入配置和限制见 docs/AI_BACKEND.md。

## 边界

12条官方岗位详情已核验，保存的是有限原文摘录和摘要，不是完整JD；收藏资格仍需本人确认。资源已核对12文档主题、6项目许可，6个项目通过限定范围实践（TodoMVC与Playwright需先应用附带补丁，审计零已知漏洞）；6视频已换为官方CS50直链并抽样播放通过。应用三浏览器24项、修复版Playwright项目21项及320/390/768px布局检查通过。真实AI仍仅模拟联调，无真实调用和账单结论。未部署；Node/SQLite本地实现不等于React/Workers/D1远端验收。4/8周后续任务为预计概览，须逐周确认写入；Offer为本人输入的七字段对比，不提供录用或合同判断。执行结果与未测项见 [测试报告](docs/TEST_REPORT.md)，资源复现见 [核验说明](docs/RESOURCE_AUDIT.md)。

.env、.local、数据库、邀请和用户备份均不进入Git。测试浏览器保留明确标记的合成演示数据。
