## 本轮补齐

- 投递记录：独立实际投递日期（允许未知）、下一步日期与过期提示；填写日期不自动更改阶段。
- 面试轮次：名称、日期、状态、问题/反馈/下一步，可新增和编辑；取消轮次通过状态记录，不删除历史来伪装结果。
- 阶段历史：每次变更先确认，记录旧阶段、新阶段、时间与说明；回退保留Offer和轮次，旧版没有历史的记录明确显示未记录，不补造。
- 编辑保护：弹窗关闭/Esc前提醒；浏览器刷新或离开有未保存内容、未完成写入或保存失败时请求原生提醒。原生提醒是否展示由浏览器及用户交互策略决定。
- 草稿与正式数据隔离：表单草稿保存在当前标签页sessionStorage；重开对应编辑窗口后主动恢复，确认前不写正式记录。支持动态岗位要求组、轮次、Offer、任务、画像等。密码/文件不采集，草稿不随正式备份导出；关闭标签页可能丢失，不代替备份。
- 保存失败回滚正式状态并保留输入；重试不会重复新增。修复画像扩展字段在事务前修改状态的问题。保存中禁用重复提交，保存状态实时更新；旧文字练习/备注自动保存失败时亦可恢复文字。
- 正式导入/清空成功后清理旧草稿，失败不清理；新字段校验兼容旧备份。
