# 启职 JobPath v0.3

岗位要求驱动的本地求职备战工作台，卡带未来主义风格。私有仓库：https://github.com/TANG1145/JobPath 。不部署上线，真实 AI 默认关闭。

## 运行与测试

Node.js 24/25 推荐（最低22.13）。运行应用无需第三方生产依赖。

```sh
npm ci
npm run dev
npm test
npm run build
```

本机访问 http://127.0.0.1:5173 。构建在dist/，仅包含客户端与资源目录，不包含服务端密钥、邀请、SQLite或后端实现。GitHub Actions只执行测试和构建，不部署。

## 功能

画像与可解释方向建议、私人JD、可视化要求分组和原文依据、技能差距、七天容量计划与先修图、任务证据、历史归档、24条分方向资源候选及文档替代、投递台账与二次确认、五题练习、简历核查、复盘补缺、Offer备注、本地JSON备份和版本冲突保护。

AI网关支持JD提取与回答反馈；发送预览、逐次同意、邀请与额度、幂等、原子费用预留、超时降级、模型输出校验。草稿经用户再次确认才保存。接入配置和限制见 docs/AI_BACKEND.md。

## 边界

24条资源入口已检查可达但仍需人工运行/播放/许可审核，不能算完整发布审核通过。真实招聘目录12条尚未完成。AI目前仅模拟联调，无真实调用与账单结论；本地SQLite不是已验收Cloudflare D1。Offer仍为自由备注；4/8周为模板概览。具体测试与未测项见 docs/TEST_REPORT.md。

.env、.local、数据库、邀请和用户备份均不进入Git。测试浏览器保留明确标记的合成演示数据。
