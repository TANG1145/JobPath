## 启动方式

双击项目根目录“启动网站.cmd”，或在项目目录执行 node scripts/start-local.mjs。入口先检查 5175 端口服务，无服务则构建并启动独立后台进程，再打开默认浏览器。关闭聊天或启动窗口不会主动停止服务；电脑重启后仍需再启动一次。服务失败详情在 .local/server.log。

固定地址 http://127.0.0.1:5175 。不要混用 localhost 或不同端口，否则浏览器个人数据空间不同。初次启动前需要 npm ci。
