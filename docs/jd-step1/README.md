# v0.7 局部完善：第 1 步 JD 整理

保留四个导航、页面布局、样式文件和原岗位要求编辑器；不迁移数据。只替换岗位卡片已有“AI 整理要求（预览）”按钮的处理流程，新增独立本机 JD 模拟服务。回答反馈、项目表达没有改动；真实 AI 关闭，没有部署。

体验：机会 → 私人岗位卡片 → AI 整理要求（预览）→ 核对原文并勾选发送确认 → 开始本机模拟整理 → 审阅候选 → 带入要求编辑 → 修改/删除后确认保存。没有私人岗位时，可先录入 JD 或收藏现有参考岗位快照。

候选按原文词面匹配，性质/技能关系/等级为明确标注的待核对默认值，不代表真实模型推理。候选与已有要求去重合并，未点击原编辑器的保存不会修改正式要求；已有未保存编辑草稿时禁止自动带入。模拟结果附在现有岗位记录 aiJD 字段内，沿用 v1 备份，无数据升级页。

本机模拟额度独立于真实 AI 邀请：每浏览器标识每天 2 次、窗口 20 次；全站每天 40 次、窗口 400 次，沿用已有预算预留限制。同标识同原文找回缓存不重复占额，更换内容拒绝；失败占额且不自动重试。模拟缓存 .local/jd-mock.sqlite 可能含原文引用，不提交 Git。随机浏览器标识仅适用于本机体验，不是生产认证方案。服务异常时继续使用原手动编辑入口。

验证：74 项规则/后端测试通过（原 70 + 新增 4）；48 项三浏览器测试通过（原 39 + 新增 9）；补充合并/取消检查后 JD 专项 9 项再次通过。检查 390/768/1280px 溢出，390px 截图人工核对。覆盖预览取消零发送、审阅后编辑、删除候选、保存前不覆盖、缓存恢复、原要求保留、断网找回、限额耗尽、并发重复、无效输出、超时及真实 AI 关闭。

本轮止步于 JD 模拟体验；真实模型质量、真实调用/计费不在已验证范围。
