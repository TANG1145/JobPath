## 正常体验路线

1. 打开 http://127.0.0.1:5175 。备战右上月历直接呈现颜色波浪；手机先展开每日打卡。
2. 机会 → 探索岗位 → AI匹配岗位：请求处理中自动出现雷达，收起后可从进度入口展开。
3. 备战 → 生成个性化计划：生成期间卡片边缘流光，结果可采用为任务。
4. 更新任务为完成并保存，进度圆环更新并短暂庆祝。求职 → Offer对比 → 添加已收到的Offer，同样在保存后反馈。
5. 日程、资源、面试、Offer等标签可正常切换；任务与求职记录可备份恢复。
