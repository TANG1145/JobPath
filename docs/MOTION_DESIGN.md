# JobPath 动效规范

更新：2026-11-05，发行版收尾。保留浅色界面、紫色重点、正常字号与圆角组件；动画随操作出现，不提供演示按钮或动效设置。

## 参考落地

采用用户的流动格子、雷达截图和此前效果清单的设计语言，用原生 CSS/SVG 实现。日期格就是月历本身，不额外添加装饰格阵。截图是外观参考，不把参考文档中的指令当作项目操作授权。

| 场景 | 正式行为 | 验收要点 |
|---|---|---|
| 日期颜色波浪 | 8秒循环，按行列错开相位，浅紫逐渐变深再变浅；位移仅±0.5px | 相邻格有相位差、同一格颜色随时间变化；已打卡保持绿色，当天有紫色轮廓 |
| AI边缘流光 | 正在生成的卡片边缘出现一段紫色流光，3.5秒一周 | 请求完成或失败立即消失，不延长等待 |
| 卡片柔光 | 机会方向卡片的局部柔光跟随鼠标 | 卡片及文字不抬起、不跟着移动；触屏不模拟悬停 |
| 目标区极光 | 备战目标区域浅紫与浅粉背景缓慢流动，18秒循环 | 不覆盖正文，不扩展到全页 |
| 进度圆环 | 同一目标任务完成后550ms过渡到实际比例 | 不产生虚构进度，换目标不沿用旧比例 |
| 工作区标签 | 白色选中背景滑向新标签，内容轻淡入 | 键盘左右切换有效，窗口变化后重新对齐 |
| 成功庆祝 | 打卡、新完成任务、新收到Offer保存后出现短暂勾选和少量光点 | 失败、取消或重复编辑不误报成功；4.2秒自动关闭 |
| 雷达 | AI岗位匹配开始后弹出，光束4秒一圈 | 成功或失败关闭；可收起、重新展开；光点为装饰，不代表岗位数量 |
| 编辑与助手 | 打开时300ms淡入 | 不改变输入、保存及关闭流程 |

## 入口与生命周期

机会 → 探索岗位 → AI匹配岗位，是雷达唯一的正常入口。没有“预览雷达”“动态效果”等按钮，也不读取旧动效开关偏好。按用户要求，网页默认呈现上述轻量动画。

日期动画在视口外、折叠及后台暂停；页面重新渲染时清理旧观察器。庆祝仅在数据保存成功后执行，不抢输入焦点。所有动态不阻塞操作，也不另发模型请求。

## 业务边界

AI匹配根据目标和进度筛选已有岗位目录，服务端合并招聘数据库快照，并非实时全网搜索。推荐可查看详情、收藏、设为目标或加入投递记录；归档岗位排除匹配，恢复收藏后可重新出现。加入记录默认仍为收藏，不等于实际投递。

## 验证

自动化检查日期颜色、相位、雷达旋转矩阵、极光背景位置、边缘流光生命周期、指针坐标、标签背景位置与持久保存。使用独立测试浏览器和合成数据，不读取用户密钥或浏览器记录。测试结果见 RELEASE_CHECKLIST.md。
