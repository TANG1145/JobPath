# JobPath网站使用说明

## 推荐路线

首次使用：设置个人目标 → 机会选择具体岗位 → 备战建立计划 → 每日执行并记录成果 → 求职记录投递/面试 → 比较Offer → 每周复盘与导出。

学习与投递可以并行，不需要完成全部学习任务才能投递。AI是规划辅助，个人动作与事实由你确认。

## 启动与数据

双击项目根目录“启动网站.cmd”，打开 http://127.0.0.1:5175 。服务独立后台运行，电脑重启后再启动一次。首次安装依赖需在项目目录npm ci。不要直接双击index.html；也不要混用localhost、127.0.0.1和不同端口，这些网址的个人数据空间不同。

个人数据存在当前浏览器IndexedDB；清理浏览器或换设备前先到设置导出备份。API Key属于本机服务端配置，不包含在个人备份里。多人共用同一浏览器应自行区分数据，当前没有个人登录和云同步。

## 设置

“调整画像”设置方向、每周时间、毕业年月、求职类型、城市、截止时间、可用日期。未知项可以留空，AI会提示核实。换方向可能需要重新选择目标，旧岗位、计划和证据仍保留。

“连接AI服务”提供网页配置。Key在DeepSeek平台申请，本机网页负责验证和保存。勾选启用后点击验证连接并保存。已有配置可留空Key仅改有效期/开关；停用后历史和手动功能继续可用。高级邀请是另一种配额访问方式，网页本机配置成功后无需手工填邀请。

## 机会

搜索技术栈或岗位方向，打开方向列表，查看公司、岗位、城市、要求、来源和核验时间。收藏会保存岗位快照，不会自动投递。进入“我的理想JD”可管理收藏、编辑要求、补充原文并设为备战目标。

“录入私人JD”适合自己找到的岗位：填名称、公司、方向与原文后保存，再选择目标。职位要求分必需/优先和全部/任一，证据来自原文。目录摘要不等于岗位完整要求，招聘状态以官方页面为准。

独立“探索18个方向”页提供球体和列表两种浏览。点击具体岗位查看，再返回工作台管理个人备战流程。

## 备战

1. 确认顶部是当前目标。
2. 手动方式：从资源库选文档/视频/开源项目，填要学的范围、预计分钟和验收目标；或者“自定义任务”。资源只是入口，不等于需要完成整套课程。
3. AI方式：设置计划周期，输入现实时间与目标，生成重点日期节点，查看后“采用为学习任务”。计划最多7个重点节点，不是自动生成52周每天数百个任务。
4. 展开“我的学习计划”，点击“编辑与记录进度”。状态可设待做、进行中、完成或暂缓。完成时写至少10字成果证据，说明独立改动、验证方式和问题，并勾选验收后保存。
5. 进度按已完成任务数计算；看过视频、收藏资料或打卡不会自动标记掌握技能。
6. “安排时间”仍可按规则安排自选任务；“时间安排与历史”提供AI生成入口及历史。AI草稿和手动排期可分别查看。
7. “规划助手”可询问今天的安排或求职问题，使用当前目标、近期任务与最近几轮对话。记录刷新保留；输入未发送不是正式对话记录。
8. 右上打卡每天记录一次学习足迹，不能替代成果记录，也不是后台自动监控学习。

## 求职

投递顺序：先写城市、毕业时间、到岗情况等现实条件，AI从当前方向目录选择具体岗位并解释行动顺序。点击官网核对资格和状态，再加入台账。没有候选时补充方向或手工录入岗位，不要求AI编造空缺。

投递台账：添加公司/岗位、投递日、下一步和日期。修改阶段需要本人确认；只打开招聘网站不会变成“已投递”。投递流程允许回退，保留历史。

面试：先有一条求职记录，再“记录面试”关联它，填轮次、日期、状态及问题/经验。AI面试建议可以采用为待安排轮次；真正完成后改为已完成并补充复盘。多轮面试均挂在同一个申请下。

Offer：可直接“添加已收到的Offer”，也可把已有台账阶段改成Offer后编辑条件。录入岗位内容、城市、薪酬结构、试用期、成长机会、截止和待问事项，多份Offer显示对照表。只记录本人收到的条件，没有自动同步企业系统的“实时Offer”。

复盘：查看近期完成与阶段变化、记录面试暴露的问题，可新增补缺任务。旧版本备注保留用于迁移。简历事实清单帮助核查贡献和证据，本版没有Word/PDF简历排版器。

## 每天与每周

每天约5分钟：检查下一步日期 → 选今天能完成的一项 → 实践后更新任务/面试状态 → 打卡。

每周约15分钟：回看已完成和暂缓 → 调整时间预算与目标 → 生成/编辑下一步计划 → 核对仍在招聘的岗位 → 导出备份。

## 演示与限制

课堂演示路线见AI_DEMO_GUIDE.md。真实AI未配置时，手动任务、记录和备份照常可用；不要把合成测试结果叫做真实AI生成。当前不提供全网实时岗位、自动投递、邮件同步、合同判断或录用保证。
