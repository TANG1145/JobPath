## 配置与运行

Node 22.13+，建议 Node 24/25。`npm ci` 安装测试依赖，`npm run dev` 启动本机127.0.0.1:5173。复制 `.env.example` 为 `.env`，默认 `AI_ENABLED=false`。`npm run invite` 创建24字节随机邀请，原文仅存 `.local/invite.txt`（权限0600），SQLite只存哈希。文件不提交Git。设置页输入邀请，存于sessionStorage，不进入备份。

后续若明确启用真实调用，须本地填入密钥、核验当日模型与价格、设置窗口截止时间，并同时开启 AI_ENABLED 与 AI_PRICING_REVIEWED。不要将密钥放前端或聊天。窗口到期按每次请求检查关闭。

## 契约和保护

GET /api/health、GET /api/quota、POST /api/ai；固定 jd_extract/answer_feedback 两种模式。请求6KB文本上限，实际body16KB上限；每次预览同意，不接受任意提示词、URL抓取或工具。固定 deepseek-flash、关闭thinking、1500输出token、JSON输出；供应商最多等待20秒，不重试。

邀请每人每天2次/窗口20次，全站每天40次/窗口400次；每次预留60000 micro_cny，总预算24000000。SQLite单条条件INSERT原子预留，唯一邀请+幂等键，成功预留才访问模型。失败和超时仍占用；费用高于预留触发持久熔断。日志表不保存输入或输出正文。跨日采用Asia/Shanghai。

价格估算沿用设计文档的输入3元/百万token、输出12元/百万token。这是保守预算假设，不是当日人民币报价或账单保证。2026-10-31 核对官网：deepseek-flash 峰时输入（未命中缓存）$0.3/百万 token、输出 $1.2/百万 token；本地仍按人民币保守估算记账（假设美元兑人民币不超过10），并非实际账单。官方页面为美元与峰谷计价，真实启用前必须另核汇率、最大输入及usage边界。无需也不应因模拟联调自动开启真实服务。

## JD 整理使用路径（2026-10-31）

1. 在 `.env` 填写 `DEEPSEEK_API_KEY`，设置 `AI_ENABLED=true`、`AI_PRICING_REVIEWED=true`，确认 `AI_WINDOW_END` 为希望结束试用的未来日期。只在准备真实使用时开启，默认示例仍关闭。
2. 停止旧服务再 `npm run dev`，避免旧进程继续使用旧环境变量或占用 5173。`/api/health` 中 `aiEnabled` 应为 true。
3. `npm run invite`，在本机打开 `.local/invite.txt`，将邀请令牌填入应用「设置 → AI 模块与限额」。该令牌不是 DeepSeek 密钥。
4. 「机会 → 我的理想 JD → 查看与整理 → AI 整理要求」。核对原文与发送对象，勾选同意后发送一次。
5. AI 返回必需/优先、全部/任一关系及原文依据；审阅后带入要求编辑器，最后保存才修改正式要求。新技能允许使用原文中的名称，不局限旧技能字典；未知信息保留为待确认项。

失败保留原文及手动入口，同一请求不重复调用上游；真实请求结束后按钮禁用。关闭并重开不会自动重发，重复原文请求标识会由服务端拒绝，避免网络不确定时重复收费。修改原文后可发起新请求。成功结果保存在本地岗位记录，可随已有备份导出；服务端费用日志不保存原文和模型输出。

测试：100 项 Node 测试通过；JD 模拟与 DeepSeek 界面流程在 Chromium、Firefox、WebKit 加收藏详情回归共 24 项通过。覆盖同意、限额、失败、禁止重复发送、引用校验、原文保留、审阅带入和保存保护。真实 DeepSeek 网络和账号调用已于下述追加验收完成；实际费用以供应商账单为准。本轮没有部署、没有合并 main。
