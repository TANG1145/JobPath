# 启职 JobPath 本地版 0.2

保留卡带未来主义控制台风格，补充岗位要求驱动的本地求职工作流。没有部署上线，没有开启 AI 或上传个人资料。

## 运行

Node.js 25.9.0 已验证；无需安装依赖。

```sh
npm run dev
npm test
npm run build
```

预览 http://127.0.0.1:5173 ，静态构建位于 dist/。

## 使用流程

1. 设置方向、自评、兴趣、每周时间、可用日期及准备截止日期。
2. 机会页录入私人 JD，编辑来源、资格、截止与要求。每条要求保留 JD 原文证据，支持必需/优先、全部/任一组合。
3. 设为目标岗位，在备战页查看已知项匹配、覆盖度和差距。自评不是录用概率。
4. 预览并确认七天计划。容量留20%机动，每天最多3项，大任务拆分，先修优先，溢出进入待办。重排保留完成记录、归档旧计划。
5. 任务完成需要验收勾选与证据。学习资料为候选入口。
6. 岗位加入台账，记录阶段与下一步；五题回答、简历核查、面试复盘补缺和Offer备注可本地保存。
7. 设置页导出/导入JSON。IndexedDB事务带版本检查，旧标签保存被阻止。

## 当前限制

尚无真实招聘目录12条、完整审核资源库24条、AI网关、云同步。要求编辑目前为逐行格式，适合内部验证，后续应改为可视化要求编辑器。任务为基础/实践两级模板，尚未建设完整技能跨领域先修图；后续周路线是概览而非正式排程。Offer使用自由备注而非结构化比较表。数据存储仍是单文档事务，保留第一版兼容格式，不完全采用设计文档的多store架构。

详细已执行测试和未测项见 docs/TEST_REPORT.md。浏览器保留明确标记的合成测试记录，方便演示。
