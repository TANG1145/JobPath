# 本机 AI API 配置指南

适用于本项目 DeepSeek 服务端网关。检查日期：2026-11-05。

## 1 获取 API Key

在 https://platform.deepseek.com/ 登录自己的开发者账号，在 API Keys 页面创建密钥并确认可用余额。聊天网页账号的会员不等于 API 余额。密钥只填在本机 .env，不要发到聊天、截图、前端输入框或 GitHub。

官方接口和价格：https://api-docs.deepseek.com/quick_start/pricing/ 。当前代码固定使用 https://api.deepseek.com/chat/completions 和 deepseek-flash，关闭思考，JSON 非流式响应，上限1500输出token。实际价格以官方后台为准。

## 2 创建配置文件

在项目根目录（和 package.json 同一层）复制 .env.example 为 .env；如果已有 .env，编辑现有文件，别覆盖自己的设置。

```dotenv
PORT=5175
AI_ENABLED=true
AI_PRICING_REVIEWED=true
DEEPSEEK_API_KEY=在自己电脑这里填入密钥
AI_WINDOW_END=2026-12-05T23:59:59+08:00
RECRUITMENT_AUTO_UPDATE=false
AI_DAILY_LIMIT=10
AI_PERSONAL_TOTAL_LIMIT=50
```

确认模型及预算后才把 AI_PRICING_REVIEWED 设 true。到期时间必须在未来。个人额度可配置（每天上限20，窗口上限100），全站每天40次、总400次及金额闸门仍生效；失败和超时也占额度。不要为了重新获得次数删除 quota.sqlite。

## 3 创建本地邀请

在项目目录打开终端执行：

```powershell
npm run invite
```

用文本编辑器打开项目下 .local/invite.txt，复制其中的令牌，到网页“设置 → AI 模块与限额”，填入邀请令牌并点击“保存邀请并查询额度”。它不是 API Key，仅用于本机调用额度。令牌只保存当前浏览器会话，不随备份导出。

## 4 重启并检查

修改 .env 后需重启 Node 服务，刷新网页不能加载新配置。可在项目目录执行：

```powershell
node scripts/start-local.mjs --restart
```

启动后打开 http://127.0.0.1:5175 。设置页应显示“AI 网关已开启”。然后在“备战 → AI 个性化计划”输入一个小需求点击生成；首次用合成内容验证即可。

如果配置失败，按以下顺序排查：

| 提示 | 检查 |
|---|---|
| AI 当前关闭 | .env 是否在项目根目录、两个开关是否 true、Key 是否填写、窗口是否在未来、是否重启 |
| 邀请无效或过期 | 是否填入 .local/invite.txt 的最新令牌；不要填写 API Key |
| 次数或预算已用完 | 设置页额度、个人限制及全站费用闸门；保留账本，别删库 |
| 模型服务暂不可用 | 开发者后台余额、密钥权限、服务端到官方端点的网络；请求不会自动重试 |
| 生成超时 | 检查网络，缩短需求后手动再试；原输入保留 |
| 无法采用任务 | 检查目标岗位、AI日期和现有任务是否超过每周80%容量、每天三项上限 |

## 5 日常操作

- 学习进度：展开“我的学习计划” → “编辑与记录进度” → 状态选进行中/完成/暂缓。完成时填写至少10字成果证据，并勾选验收，再确认保存。首页进度随已完成任务更新；打卡只记学习足迹。
- AI学习路线：在“时间安排与历史”设置周期 → AI制定新计划。建议生成到时间线和计划卡片；点击“采用为学习任务”才新增可追踪任务，不覆盖旧成果。
- AI投递规划：先调整画像中的城市、求职类型和毕业时间，再在求职页补充现实情况，生成岗位参考顺序。具体岗位来自目录，有官网入口；招聘状态和资格仍需核对。当前不提供全网实时搜索。
- 面试：点击“记录面试”，关联求职记录，填写轮次、日期、状态和经验；实际完成后改为已完成。AI建议可采用为待安排轮次。
- Offer：点击“添加已收到的Offer”直接录入，或把台账阶段改为Offer后编辑条件。两个以上Offer会横向显示逐项比较表，修改后立即更新；不是自动接收公司Offer的实时服务。

真实API尚未在此次开发中调用；自动测试使用合成模型结果，不产生模型费用。
