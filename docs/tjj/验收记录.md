# tjj 机会页面改进

基于 v0.7；独立 tjj 分支，不合并 main、不部署，真实 AI 关闭。

## 使用

打开 http://127.0.0.1:5173/，进入“机会”。点击分类水晶球进入具体公司招聘，支持分类技能搜索、分类内岗位搜索及招聘类型筛选。“查看已保存 JD”集中展示私人 JD 和招聘收藏。

8 类、21 条去重记录（跨分类引用不重复计数）。原有三方向 JD 保留设目标、编辑和模拟整理；新增分类仅保存招聘摘要及来源，不自动生成学习计划、不提交申请。收藏保存在本机浏览器，支持原有备份导出/回导。

## 验证

- npm run build：通过。
- npm test：77 项通过。
- Playwright：72 项通过（Chromium、Firefox、WebKit）。
- 覆盖八类跳转、返回焦点、搜索空态、类型筛选、收藏刷新与去重、原有 JD 流程、备份字段校验、390/768/1280 宽度、WebGL 与强制降级、减少动态效果、跨页清理、AI 关闭、历史保存保护。
- 官方站点可能需要脚本加载或已结束招聘；自动化测试验证本地交互，不代表远端岗位仍在招。
