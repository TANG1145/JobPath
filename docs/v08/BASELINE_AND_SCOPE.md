## 旧数据映射

- 旧私人岗位 → Job + 第一个 Snapshot + Requirement；原文和依据保留。
- 旧任务 → 稳定任务 ID；非空证据 → 标记“旧版自报”的独立成果，不伪装外部验证。
- 旧投递 → Application、Round、事件；未知归属为 pending，可在设置中人工关联。
- 旧计划 → 历史完整原文和可迁移计划条目；旧 Offer 自由备注 → 历史资料，不猜测属于哪个岗位。
- 旧回答 → legacy 会话和答案；缺失题目为空，历史反馈标上下文待核对。
- 原始 v1 全量备份保存在恢复区与 history；无法结构化的额外字段不静默丢弃。

## 恢复操作

1. 首次访问旧浏览器时先显示迁移数量预览。先下载旧格式副本，再确认升级；旧 `jobpath-v1` 数据库不清空。
2. 设置可导出 v2 完整备份（含草稿），也可下载升级/导入/清空前副本。备份含私人正文，应自行保存。
3. 导入 v1/v2 均先预览，再确认覆盖；不会自动合并。清空前也保留恢复副本。
4. 要退回 v0.7：先导出 v2 保存本轮新增内容，再使用独立旧版检出和升级前 v1 副本。**v0.7 不能读取 v2，新版新增内容不会自动反向迁移**。不要删除原始数据库或恢复文件。
5. 浏览器清理仍可能删除本机数据库及其恢复区；本机恢复副本不能替代下载到浏览器外的备份。

- 真实岗位状态、视频与项目资源沿用既有核验结果，本轮未重新验证外网时效。链接随时可能变化。
