# JobPath v0.4 本地验收记录

日期：2026-10-30。环境：macOS、Node.js 25.9.0、内置浏览器。真实 AI 关闭；没有部署或提交招聘申请。本文件描述实际执行结果，未执行项不计通过。

## 本轮修复和新增

- 官方岗位目录：12条、三个方向各4条，来自字节跳动、沐瞳科技、得物、美团四个招聘品牌；即使沐瞳与字节合并计数仍满足三家。只存官方详情、资格、原文摘录、摘要、核验日期和投递入口证据，不推测薪资或截止日。
- 页面可访问、要求摘录已核验、投递入口仍开放分开记录。两条明确关闭的岗位只在历史区显示；超过7天提醒复核、超过30天转历史，未来/非法时间或未知状态不计当前机会。相同公司/方向/职位跨城市不重复计数。
- 收藏为独立版本快照，资格默认为待确认；去重，目录更新不覆盖私人记录，不自动投递。公开目录不包含用户JD。
- 要求编辑支持补充原始JD；原文证据必须存在于编辑后的文本。目录只摘录部分要求，未覆盖的任一选项不强行缩成已支持技能，匹配页不显示完整岗位总分。
- 修复资源备用文档错误匹配：现在必须同技能。项目许可、固定提交、运行范围和视频播放状态逐项展示。视频链接落到原频道具体课程。
- 修正健康接口版本号为0.4.0，保持AI关闭。

## 岗位来源核验

完整可复查记录见 [public/catalog/v1/jobs.json](../public/catalog/v1/jobs.json)。12条均实际打开官方详情，读取资格/要求并检查投递入口，没有登录或试投递。开放状态是当时页面证据，不是录用资格或实时可投保证。百度列表可读但详情导航异常，没有据此填入已核验目录。旧美团测试岗明确“当前职位无法投递”，旧字节剪映前端岗明确“该职位已下线”，均排除在当前12条外。

公开内容为有限摘录和人工摘要，不是完整JD转录。所有公开快照的 `requirementsComplete=false`；仍需在原站核对全部条件，必要时在本地补充全文。资格不能根据技能分数推定。
