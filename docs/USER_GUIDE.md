# JobPath 网站使用说明

更新：2026-11-05，适用于明亮工作台版本。

## 第一次使用

1. 双击项目根目录“启动网站.cmd”，打开 http://127.0.0.1:5175 。电脑重启后重新启动服务。
2. 进入 **设置 → 个人目标 → 编辑个人目标**，填写方向、每周时间、毕业时间、求职类型、城市、可用日和截止日期。兴趣与项目经历在可选折叠区。
3. 在 **机会 → 探索岗位** 选择方向，筛选招聘列表，打开详情查看职责、申请条件与官网。点击“收藏岗位”。也可以通过右上“添加岗位”保存自己找到的JD。
4. 在 **机会 → 收藏岗位** 打开岗位，“设为目标岗位”后进入备战。各目标的任务、AI计划和排期独立保留。
5. 想使用AI时，到 **设置 → AI连接** 配置已有Key，具体见AI_CONFIGURATION.md。

学习和投递可以并行，按现实准备程度选择行动。

## AI寻找岗位

进入 **机会 → 探索岗位 → 发现更适合你的岗位**，选择方向、补充城市或实习偏好，点击“AI 匹配岗位”。雷达表示正在分析，点击收起或按Escape可继续浏览，右下入口能再次打开；返回结果后窗口结束。雷达只在这次AI匹配处理中自动显示，没有单独的动效入口。

结果包含具体目录岗位、推荐理由、准备建议和官网来源。可以“查看岗位”核对条件、“收藏岗位”后设为备战目标，或“加入投递记录”持续跟进。已有记录会显示“查看投递记录”。这一步只新增“收藏”阶段，不代表已经投递。结果刷新后保留，也包含在个人备份中。

匹配范围为网站已有岗位目录，不能视为实时全网招聘搜索。没有合适结果时可修改方向和偏好再试；明确截止与已归档/移除的岗位不进入新匹配。

## 收藏 归档与投递记录

收藏岗位用于保存感兴趣的工作；“正在考虑”是你还准备跟进的岗位。“归档”把暂时不考虑的岗位移入“已归档”，不会删除岗位资料、学习任务或已有投递记录。

在 **机会 → 收藏岗位** 顶部点击“已归档”，即可查看数量和岗位；打开“更多 → 恢复收藏”可移回正在考虑。归档后也可点击提示中的“查看归档”或“撤销”。归档当前备战目标会解除目标；恢复收藏后可重新设为目标，原有学习计划仍保留。立即撤销归档会在未选其他目标时恢复原目标。

“投递记录”就是个人求职进度表：记录公司和岗位、是否已投递、笔试/面试阶段、下一步行动与日期。它与收藏岗位分别保存：收藏表示感兴趣，投递记录用于持续跟进。网页不会替你自动投简历。面试时间线记录具体轮次和经验；Offer对比整理已经收到的录用条件。

## 备战：计划、执行与进度

顶部显示当前目标、完成任务比例、剩余任务和预计投入。右上月历可记录今天的学习；手机上点击“每日打卡”展开。日期小方格的颜色会像波浪一样缓慢错峰变化，日期与打卡数据保持真实；不再显示额外的紫色格子。点击“记录今天的学习”并保存成功后出现庆祝浮卡，当天不会重复打卡。动画随正常操作自动呈现，无需设置。

**学习任务**：点击“新建任务”，填写任务、主题、预计分钟与完成目标。也可以在“学习资源”选择资料，填自己要学习的部分。任务列表可以折叠，展开后在固定高度内滚动，不会随任务增加不断拉长页面。

**更新进度**：任务右侧“更新进度”，选择待做、进行中、完成或暂缓；可编辑安排日期。标完成时填写具体成果与验证方式并确认验收，保存后顶部进度更新。已完成任务可“查看成果”。上移调整顺序；移除仅影响当前目标中未完成任务。

**AI计划**：在“AI 学习计划”描述目标、时间与期望结果，点击生成。结果保存在当前目标的计划档案；“采用为学习任务”新增可追踪任务，原记录和证据保留。再次生成会增加一份新方案，不覆盖旧方案。没有强制7节点、90分钟或每日三项上限。

**日程与计划**：周视图按真实任务日期显示，左右切周，“本周”返回当前周。点击日历任务即可修改；没有具体小时的数据只显示日期，不假装精确到时段。可以自定义周数，让AI制定新计划；AI结果位于“学习任务”，同时进入AI时间线。原手动排期与历史在折叠区。手动“安排时间”按自己的完整每周时间、可用日、截止与先修关系生成预览，确认后保存整个周期的已排任务；排不下的任务继续保留。

**备选岗位**：保留一个主要目标，在此补充现实情况并点击“AI 规划投递顺序”。AI根据目标类型、个人信息和现有进度推荐同期可并行准备的岗位，说明可复用准备内容、额外投入与行动日期。结果按主要目标关联，更换目标不会混入旧结果；可核对来源后加入投递记录。推荐来自项目岗位目录，并非实时全网搜索。

**学习资源**：方向、类型与搜索组合筛选。展开资料查看范围、许可与运行说明，再进入原站学习或加入目标计划。

**规划助手**：点击右下浮动按钮，输入“今天45分钟该先做什么”等学习或求职问题。对话使用目标、任务、申请及本目标的对话记录；刷新后保留。关闭按钮或Escape收起。发送时直接生成，失败显示在原按钮旁，文字保留，可主动重试。

打卡、收藏和观看资料不会自动把任务标成完成。

## 求职：按阶段使用标签

**投递记录**：新增公司/岗位、实际投递日、下一步行动和日期。在记录内修改阶段，可前进或回退，保留历史。同一申请下可记录多轮面试。记录按序号和白紫交替底色区分。“当前阶段”选择“自定义…”可填写自己的阶段名称，阶段历史和备份均保留。

**面试日历**：展示投递记录里的实际面试轮次，支持周视图、日视图、日期选择和前后翻页。桌面默认周视图，手机默认日视图。选择关联记录后点击“安排面试”，填写日期、开始/结束时间、轮次及状态；点击已有日程可编辑。重叠面试并排显示；只填日期的记录放在“时间待定”行，没有日期的记录在下方折叠区。完成后改为“已完成”会显示绿色，取消的轮次保留在投递记录中，不再占据日历。

**Offer对比**：直接添加已收到的Offer，或把投递记录阶段改为Offer，再录入条件。桌面横向比较岗位内容、城市、薪酬原始口径、试用期、成长机会、回复截止与待确认事项；手机显示逐项卡片。编辑后立即更新。同一份数据同时出现在投递记录和对比页，没有企业自动同步。

**每日回顾**：左侧按月份折叠回顾文件，右侧选择日期，编辑或阅读当天日志。编辑区支持 Markdown 标题、列表、链接、表格、代码块及引用，工具栏可插入常用格式。“保存回顾”正式保存；输入中的草稿在本标签页刷新后可以恢复。旧版回顾和补充备注位于“旧版记录”。已保存日志可删除，并包含在个人备份中。

## 设置与数据

个人目标、AI连接、数据管理各有独立标签。Key由供应商平台创建，本网页负责验证和保存；不设置网站自创的日次数、累计预算或试用到期。可主动停用AI。

在 **数据管理** 导出或恢复备份。备份包含岗位、学习记录、计划、AI结果、对话、投递、面试、每日回顾和Offer；不含API Key。导入会替换当前个人状态，先保存好原备份。清理浏览器或换电脑前导出。

固定使用127.0.0.1:5175，不混用localhost和其他端口。个人数据属于当前浏览器，没有账号云同步。多人协作共享的是Git代码；个人记录需自己管理。

## 每天与每周

每天：查看日程和下一步 → 做一项任务 → 更新成果或面试经验 → 打卡。

每周：复盘暂缓原因 → 调整可用时间与目标 → 生成或编辑下一周计划 → 跟进投递 → 导出备份。

课堂展示可按AI_DEMO_GUIDE.md进行。未配置AI时可使用手动任务、排期与求职记录。


## 学习成果的本地文件

备战 → 学习任务 → 更新进度 / 查看成果 → 成果文件 → 选择本地文件。Windows会打开原生文件选择窗口，可一次选择多个文件。随后点击“确认并保存”，将文件关联保存到该任务。

下次查看成果时，点击文件名，会打开本机文件资源管理器并选中该文件。移除只取消任务中的关联，不删除原文件。取消选择不改变已有成果。文件被移动或删除后，重新选择其新位置即可。

这是本地文件关联，不上传云端、不读取或复制文件内容。任务备份包含文件标识与名称，实际路径关联保存在此电脑项目的.local/evidence-files.json中，不提交Git。换电脑或只恢复任务备份时，需要在新电脑重新选择文件。网页需由本机服务启动，系统文件选择与定位目前支持Windows。
