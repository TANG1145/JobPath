# 分类顶部优化

日期：2026-10-30。分支：tjj。按本轮第 11 项限定范围实施，不修改收藏确认/跳转、私人 JD 录入、备战模板或归档流程。

## 改动

- 全部 18 个分类共用轻量页签；进入招聘列表仍选中“探索岗位”。收藏数量使用小徽标。
- “‹ 全部方向”返回时保留分类关键词与滚动位置；顶部“探索岗位”同样返回原浏览位置。
- 分类标题只显示方向名，一句短介绍配合默认收起的“方向介绍”；能力、常见技术与备战方向操作移入折叠区。
- 搜索、招聘类型、招聘状态紧凑排列；手机为搜索一行、两个下拉框一行。筛选值直接可见，完整无障碍名称保留。
- 结果数量取实际筛选结果；偏离默认条件时显示清空操作，无结果提供同一入口。清空恢复“校招与实习 / 可投或待核验”。
- 核验信息采用北京时间；最近检查按本分类岗位的检查记录展示，明确不代表全量更新。成功更新时间未单独记录，因此不以任务时间推断。
- 键盘可展开核验说明，显示后台任务状态、异常含义及定时配置。服务端增加 scheduleEnabled 只读元数据，只有真实启用时才显示每日 09:00。
- 将“官网可投”改为“核验时有投递入口”，资格区域提示申请条件以官网为准。原始招聘数据和收藏数据未改动。

构建通过，90 项单元测试全部通过，102 项 Playwright 测试全部通过（Chromium、Firefox、WebKit）。新增测试覆盖 390px / 768px / 1280px 无溢出、首条招聘进入桌面首屏、页签选中、筛选与计数、清空、键盘折叠、返回搜索与位置、检查时间语义、实际定时配置。旧球体测试更新为共享渲染与同款静态帧断言。
