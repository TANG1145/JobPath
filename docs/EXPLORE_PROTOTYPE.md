# 探索原型 / tb-explore

日期：2026-10-31　分支：`tb-explore`（从 `tb-dev` 切出）　状态：可运行视觉原型

## 1. 目标

这是 B 方向（探索优先）的第一块原型，不是最终 B 集成分支。

先验证三件事：

1. **水晶球式方向探索**是否比原来的岗位列表更有吸引力；
2. 拖动、点击、搜索、列表降级能否组成一个完整交互；
3. 在不引入 React/matter.js/WebGL 的前提下，这套视觉能不能先站住。

如果原型通过，再把同样的页面接进 `tjj` 基座：18 个方向、96 条资源、36 条招聘记录、React Bits Strands 与真实采集后端。

## 2. 怎么打开

启动本地服务后访问：

```
http://127.0.0.1:5173/explore.html
```

机会页顶部也增加了「◎ 探索 18 个方向」入口。

## 3. 交互

- **拖动**：按住球体移动；松手后保留速度，球体继续惯性漂移。
- **点击**：选中方向，左侧详情更新为该方向的职责、能力关键词和当前核验岗位数。
- **悬停**：球体停止漂移并增强内部光带，方便点击。
- **搜索**：按方向名、代码、描述、关键词过滤；`/` 聚焦搜索框，Esc 清空。
- **列表视图**：球体 / 列表一键切换；列表适合键盘、窄屏和读屏。
- **随机一颗**：从当前搜索结果里随机选一个方向。
- **移动端**：≤760px 自动切换为三列 CSS 网格，不运行物理引擎；点击后详情滚动到可见位置。
- **减少动态效果**：`prefers-reduced-motion` 下停止漂移与旋转。

## 4. 视觉语言

- 黑玻璃球体：径向渐变球体 + 模糊彩色等离子层 + 镜面高光 + 内阴影。
- 每个方向有自己的 `--accent`（琥珀、绿、陶土、米白）；一个球只点亮一种主色。
- 背景是圆点/网格场地 + 暖色环境光 + 暗角；没有外部图片、字体或 CDN。
- 选中态是虚线旋转环；悬停是局部光带增强；不是整页发光。
- 页面外壳沿用 `tb-dev` 的米色顶栏、深橄榄底、琥珀强调色。

## 5. 数据边界

- 18 个方向标题、代码、描述、关键词来自 `tjj` 分支的 `src/opportunity-categories.js`，复制到本分支的 `src/explore-data.js`，没有改内容。
- 岗位计数只来自当前 `publicJobs` 的 3 个方向（Web/Java/测试），所以只有这三个方向显示 4 条；其余 15 个方向明确显示“当前三方向目录暂未覆盖”，不伪造岗位。
- 方向详情底部的「去机会页」只回到现有工作台；不做新的招聘数据接入。
- 原型不写入 IndexedDB，不改变画像、目标岗位、计划或备份。

## 6. 为什么先不用 tjj 的 Strands

`tjj` 的 Strands 是 **WebGL 背景渲染器**（React Bits 参考实现 + matter.js 物理），不是现成的可交互方向控件；它的构建会引入：

- 生产依赖 React 19 / react-dom / matter-js / playwright；
- esbuild 打包与 `public/visuals/strands.js`；
- WebGL 上下文、共享 renderer、`strands-still` 降级图；
- 采集调度器相关的后端范围。

原型先使用 DOM/CSS 球体 + 轻量物理，验证“方向探索”这件事本身；如果视觉和交互成立，再把 Strands 作为球体内部纹理/背景接入 `tjj` 基座，而不是重写整个原型。

## 9. 已知限制

1. **只验证交互，不验证真实 Strands 渲染**；未接 React/matter/WebGL。
2. **15 个方向没有岗位数据**；这是现有 3 方向目录的边界，不是视觉原型要解决的问题。
3. **没有持久化**：选中方向不写入画像，刷新回到 Web 前端。
4. **没有和 18 方向招聘目录打通**；详情里的「去机会页」只到现有工作台。
5. **物理球体存在移动目标点击成本**；已加 hover 暂停和列表降级，但真机触屏仍需走查。
6. 未合并 `main`，未部署，未 push 时需先确认分支。
